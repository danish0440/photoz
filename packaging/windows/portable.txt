PhotoZ portable mode

While this file sits next to photoz.exe, PhotoZ keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the PhotoZData folder beside it, and writes
nothing to %APPDATA% or %LOCALAPPDATA%. Copy the whole folder to move PhotoZ with its settings.

Delete this file to use the normal per-user folders instead: %APPDATA%\Photoz for settings
and %LOCALAPPDATA%\Photoz\Recovery for crash-recovery autosaves. If PhotoZData can't be
written (for example on a read-only drive), PhotoZ says so and uses those folders instead.
